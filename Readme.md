# E-Commerce Performance Dashboard (2024-2025)

## Project Overview
This Power BI dashboard provides insights into sales performance, customer behavior, revenue trends, profit analysis, and category performance.

## Features
- Total Orders Analysis
- Revenue Tracking
- Profit Analysis
- Customer Segmentation
- Brand Performance
- Category Analysis
- City-wise Revenue Analysis
- Monthly Sales Trends

## Tools Used
- Power BI
- DAX
- Power Query
- Excel Dataset

## Dashboard Preview

![Dashboard](dashboard.png)

## Key Insights
- Electronics category generated highest revenue.
- January recorded highest sales.
- Male customers contributed majority purchases.
- Total Revenue exceeded 1 Million.
